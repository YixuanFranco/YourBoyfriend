# 💙 YourBoyfriend · 蓝盆友

> **11 年前，有人在这里许了一个愿：想要一个"智能男朋友"。**
> **2026 年，AI 时代到了。我们回来，兑现它。**

这个仓库出生在 2015 年 12 月 1 日，一句玩笑开场："我可能是命中注定要去开发这套系统的人。"

那之后的十一年，我们被追着骂"一行代码都没有"，也被温柔地投喂了 **200+ 条愿望**——"会震动""会喘息会叫""帮我改 bug 脾气要好""永生的肉体对其它人都是种压力""虽然我是一个男的，可是我也想要一个蓝盆友"。这些愿望一条都没丢，它们都在 Issues 里，一条比一条认真。

当年不是不想做，是真的做不到：微信机器人会挂、语音像机器人、没有人格、没有记忆、没有形象——一行代码撑不起一个"他"。

2026 年，墙塌了。大模型、情感计算、语音克隆、数字人、IoT、连情趣硬件都有了 API——**当年接不住愿望的技术，现在全都在。AI 实在太牛逼了，我们回来重启这个项目。**

## 🔭 我们在调研什么（截至 2026-10）

重启不急着写代码——先把十年的愿望吃透，再决定做什么。当前在跑这些方向：

1. **需求真相**：把 219+ 条许愿逐条判读，分清真需求（情绪价值、陪伴、归属）和假需求（玩梗、观光——它们是社区资产，喂传播）
2. **人类可量化评价体系**：身体 / 思维 / 环境 / 命理 四域 × 40+ 维度，合成一张"全方位雷达图"，再做成 Survey 问卷——填自己 → 出雷达 → 匹配适合你的人（或 AI 伴侣）
3. **双模式**：许愿模式（YY / 身心灵，给你做梦的）vs 现充模式（实打实找对象，给你落地的）——两个都要
4. **地域环境坐标基准**：不同地域的人在一起，会遇到什么惊喜、什么困难（口味、气候、习惯、过敏原——全部带环境成因，不贴地域标签）
5. **感知 → 具身闭环**：从"会聊天"到"会疼你"——记忆、主动关怀、IoT 硬件
6. **合规分级**：《人工智能拟人化互动服务管理暂行办法》已施行，G / PG-13 / R 三档闸门是我们引擎里的一个字段，不是事后补

**调研是持续进行的。** 每完成一轮，我们会把结论更新到 [wiki](https://github.com/YixuanFranco/YourBoyfriend/wiki) 和本 README 的"调研动态"；也欢迎你在 [issue #2](https://github.com/YixuanFranco/YourBoyfriend/issues/2) 点名下一个方向。
