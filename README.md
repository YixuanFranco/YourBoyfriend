## 🎴 核心玩法：34 省角色卡生成器（MVP）

我们把它做成一个**决策树 / 嵌套 list 遍历引擎**，每个角色 = 逐层走一遍：

```
L1 关系方向   → 男友 / 女友 / 无性别
L2 地域出身   → 34 省级（身高 / 方言 / 地域梗 / 饮食 / 节日）
L3 人格类型   → 10 款男友：男神 / 暖男 / 高冷 / 高智商 / 宅男 / 潮男 / 二逼 / 书生 / 闷骚 / 忠犬
L4 声线       → 类型 × 地域 推荐组合（方言口音 = 记忆点）
L5 技能包     → 关怀 / 任务 / 娱乐（从需求清单勾选：订饭、哄睡、改 bug、带打游戏……）
L6 关系阶段   → 暧昧 / 热恋 / 稳定 / 老夫老妻
L7 内容分级   → PG-13（默认）/ R（海外成人档，合规闸门）

输出：可运行的伴侣角色卡（JSON schema）→ 对话引擎 / 形象 / TTS / 硬件模块消费
```

- 组合爆炸：34 省 × 10 款 × N 声线 × M 技能 = **千级角色池**，天然适合投票、分享、二创。
- 省域素材库（身高榜/地域梗/人设标签）见 [灵感库 · 地域男友图鉴](https://github.com/YixuanFranco/YourBoyfriend/wiki/地域男友图鉴)。
- **第一期能玩什么**：输入省份 + 身高 + 性格标签 → 生成 5 字段角色卡（形象参数 / 性格 traits / 口头禅 / 声线参数 / 剧情小传）→ 微调 → 导出分享。

## 🏗️ 双轨制：开源内核 + 商业外壳

这个项目两条腿走路，共用同一个引擎：

| 轨道 | 内容 | 谁在用 |
|:---|:---|:---|
| **开源内核** | 角色卡解析引擎、对话编排、人设系统；个人可本地跑 | 开发者、玩家、二创社区 |
| **商业外壳** | 托管服务、角色卡市场（创作者分成）、企业定制 | 不想折腾部署的用户、IP 方 |

- 开源内核用 **AGPL-3.0 + 商业双许可**（原 WTFPL 版本保留为"礼物版"）：社区永远免费，企业商用买例外许可——这是 SillyTavern、Redis 验证过的路线。
- 角色卡市场：创作者定价卖卡、平台抽成（70/30）。隔壁 Character.AI 1800 万个角色创作者一分钱拿不到——**我们要做给创作者分钱的那个**。

## 🔞 合规分级：我们不装看不见

2026-07-15 起，《人工智能拟人化互动服务管理暂行办法》已施行。我们把合规做成引擎里的一个字段（`content_rating + age_gate`），而不是事后补：

| 档位 | 定位 | 年龄闸门 | 渠道 |
|:---|:---|:---|:---|
| **G 档** | 纯陪伴/伙伴，无浪漫指向 | 实名 + 未成年人模式 | 国内应用商店 |
| **PG-13 档** | 暧昧、轻撩、虚拟恋爱称呼 | 实名 + 18+ 验证 + 2h 防沉迷弹窗 | 国内订阅档 |
| **R 档** | 成人档（仅海外 Web） | 信用卡验证 + 年龄自证 | 海外独立站 |

- **未成年人禁入恋人模式**是硬红线（新规第 14 条），不做任何变通。
- 提示词层禁止越狱式改写（行业前车之鉴：Alien Chat 案，主犯获刑 4 年）。
- 国内版与海外版**物理隔离**（不同主体、不同模型实例、不同数据链路）。

## ⚖️ 变现与合规说明

- 本项目是**开源 + 商业化双轨**：内核永远开源免费；托管、卡市场、企业定制属于商业外壳。
- 国内版严格走 G / PG-13 档，遵守《人工智能拟人化互动服务管理暂行办法》全部义务（安全评估、算法备案、未成年人模式、2 小时弹窗、人工干预）。
- 成人档（R）仅面向海外市场运营，与国内版物理隔离；我们坚决不向未成年人提供任何亲密关系服务。
