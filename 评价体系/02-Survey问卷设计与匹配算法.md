# 02 · Survey 问卷设计与匹配算法

> 用途：伴侣工厂冷启动问卷——用户填自己（底层 = 身体 + 思维模式 + 环境）→ 输出自我雷达图；填理想伴侣期望 → 输出理想雷达图；雷达匹配度推荐"你更适合怎样的人/角色"。
> 依据：《01-人类可量化评价体系总表》轴定义 + 建模 02（需求发现器，输入端）+ YG#2 作者 2016 年"需求量化建模/择偶树"原型。
> v1.1（2026-10-29）：新增双模式入口（§一.1，配套《05》）与进阶可选模块（模块 E/F，配套《04》）。

---

## 〇、问卷定位

- **输入端，不是输出端**：建模 02 已论证——用户的需求是模糊的（"大部分人说的都是很泛的东西"），产品第一步是"发现器"：帮用户把"想要一个男朋友"翻译成具体的维度画像。
- **三步走 + 模式选择**：选性向 → 选模式（许愿/现充/都要，见 §一.1）→ 填自己 → 填理想 → 看匹配与推荐（自我雷达 / 理想雷达 / 匹配度 / 角色推荐或现实建议）。
- **轻量可玩**：全问卷 10 分钟内完成；每题可跳过（敏感字段跳过不扣分，仅标签缺省）。

## 一、性向分支（问卷第 0 步）

进入问卷先选"你是谁 × 你喜欢谁"：

| 分支 | 说明 | 影响 |
|:---|:---|:---|
| 女 × 喜欢男 | 异性恋女性 | 自我画像性别=女；理想伴侣画像性别=男；身高轴用对应性别均值 |
| 女 × 拉拉 | 同性恋女性 | 两者均按女性均值成图 |
| 男 × 喜欢女 | 异性恋男性 | 自我=男；理想=女 |
| 男 × 喜欢男 | 同性恋男性 | 两者均按男性均值成图 |
| 非二元 | 性别非二元 | 身高/身材轴按用户自选参照系或默认中立 |
| 无性恋 / 泛性恋 / 尚不确定 | 扩展可选项（已增补，见待拍板 P11） | 理想画像可选"不需要/无性别" |

> 对应"伴侣工厂"角色卡引擎 L1（关系方向）：本问卷的"理想伴侣画像"输出可直接作为 L2（地域）/L3（人格）/L4（声线）的推荐输入。

### 1.1 模式入口（问卷第 0.5 步，配套《05 双模式》）

> "你想怎么玩？"
> A. 先许个愿（好玩为主，看看我的命定伴侣什么样）→ 许愿管线
> B. 认真找对象（帮我看清自己、给我现实建议）→ 现充管线
> C. 两个都要（先许愿，再看现实）→ 双输出

- **不是两个独立问卷**：三块题目 + 命理快排完全共用，只有入口问题不同。
- 许愿管线：命理/浪漫轴权重上调、安全信用轴下调，输出缘分卡/角色卡/合婚解读（标注"仅供娱乐"）。
- 现充管线：环境/健康/信用轴权重上调、命理仅作趣味，输出定位/适配人群/行动清单。
- 双输出：同一雷达出两份报告并排对比（"命定 vs 现实"反差即传播点）。

### 模块 D · 命理快排（可选，约 1 分钟，趣味层）

- 输入：出生日期（必）+ 出生时辰（选）+ 姓名（选）。
- 自动输出：八字五行分布 / 生肖与属相配对 / 星座 /（若给时辰）紫微命宫主星 /（若给姓名）五格吉度。

## 四、匹配算法（雷达匹配度）

### 4.1 数据准备

- 两幅雷达图各 16 轴，值域统一归一化到 [0,100]。
- 命理 2 轴默认权重 0（可开关）；敏感轴（颜值）若跳过则该轴在计算时剔除（避免缺省拉低分数）。

### 4.2 主算法：加权欧氏距离（相似度）

```
d = sqrt( Σ_i w_i · (x_i - y_i)² / Σ_i w_i )

相似度 S_euclid = 1 - d/100   （0~1，越接近 1 越契合）
```

- 默认等权 w_i = 1；高级设置允许用户自定义权重（待拍板 P7）。
- 心理轴（情绪稳定/温柔宜人/亲密安全）建议"互补加权"：理想温柔度高 ↔ 自我温柔度高 加分（同向），但"情绪稳定 × 情绪稳定"与"稳定 × 略有波动"都可接受（可调）。

### 4.3 辅算法：余弦相似度（形状匹配）

```
cos = Σ x_i·y_i / ( sqrt(Σ x_i²) · sqrt(Σ y_i²) )
```

- 关注"画像形状"是否相似（高矮胖瘦分布一致），忽略整体高低。
- 用途：两个"整体分"不同但"形状"很像的人（如都偏文艺安静），余弦分高——适合推荐"同类人"。

### 4.4 综合匹配度

```
Match = 0.7 × S_euclid + 0.3 × cos
```

- 欧氏主、余弦辅：既看差距绝对值，也看形状。

### 4.5 阈值与话术（待拍板 P9）

| 综合匹配度 | 判定 | 推荐话术（示例） |
|:---|:---|:---|
| ≥ 0.8 | 高度契合 | "你们是同一个星球的人，从性格到生活节奏都对得上。" |
| 0.6 - 0.8 | 适合 | "有很好的化学反应，也有值得磨合的地方——比如 TA 更外向。" |
| < 0.6 | 需磨合 | "你们差异不小，但差异不一定坏事——互补型关系参考。" |

### 4.6 角色推荐（映射到角色卡引擎）

- 理想伴侣雷达的 16 轴 → 反推角色卡推荐：
  - 地域推荐（L2）：理想地域标签 or 若未填→按理想性格雷达匹配最近的大区（用地域性格雷达 6 轴余弦）。
  - 人格推荐（L3）：理想"温柔宜人/外向/尽责"分值 → 映射男友 10 款（温柔高分→暖男/忠犬；外向高分→潮男/男神；尽责高分→高智商/书生）或女友 8 款。
  - 声线推荐（L4）：人格 × 地域 → 推荐声线组合（如"东北 × 忠犬款 = 雪乡直球老铁"）。
  - 关系阶段（L6）：由理想"亲密安全/家庭温度"分 → 建议从暧昧还是热恋档开始。
- 输出一条可运行的"伴侣角色卡"（对接 mvp 角色卡生成器的 JSON schema）。

## 五、问卷数据与建模 02 的呼应

- 问卷第 0 步性向分支 ↔ 需求场景 7（性别/性向自由，+32 赞）。
- 模块 B 情绪/依恋题 ↔ 真需求 T1/T2（陪伴、被接纳）与"脾气好"最高频词。
- 模块 C 环境题 ↔ 相亲角"条件匹配"与资源位；同时回答建模 02 待拍板"先验证深夜陪伴还是 T3"——**问卷把两件事都做了**：陪伴型用户（高孤独、高依恋焦虑）与亲密型用户（性向+理想亲密分高）会被自动分流到不同推荐路径。
- 命理快排 ↔ 用户"八字定人格"原型（丙午辛卯辛卯戊寅）与合婚文化，做对话破冰与趣味分享。

## 六、惊讶指数高的发现（问卷相关）

1. **算法婚恋的残酷漏斗**：浙大 MatchUs 披露匹配成功率 30-40%，但其中最终发展为稳定情侣的只有约 6%——问卷匹配只能当"开场白"，不能当"结论"（《中国青年报》2026-07-21）。
2. **年轻人已把问卷当"相处说明书"**：上海交大 CampusDate 65 题问卷甚至包含"恋爱日常开销倾向""吃不吃辣"——匹配报告被用户称为"提前写好的相处说明书"（B 档 2026）。
3. **父母代与子女代的评价维度分裂**：父母辈用学历/房产/年薪/父母职业"条件筛选"，年轻人转向"合得来"（价值观/生活颗粒度/吵架处理方式）——问卷设计要同时服务两代人，或干脆只服务年轻人（B 档）。
4. **2016 年的"炮灰数量"**：你的 YG#2 需求量化建模里用 TED 数学公式算"炮灰数量"——10 年后这套"择偶打分器"思路以问卷+雷达图的形式回来了（你的原话，Issue 记录）。
