# 06 · 地域环境坐标基准与跨地域结合预测

> 为每个地域建立"绝对环境坐标"（不是排名），并为跨地域结合提供可复用的"差异矩阵规则引擎"。
> 四大层：绝对坐标 / 身体反应 / 工作生活习惯 / 饮食口味（带成因解释）。
> 版本：v1.0 ｜ 2026-10-29 ｜ 反地域歧视红线与《04》§3.2 衔接
> 轻量调研（各 1-2 来源）支撑，非重调研；来源见 §八。

---

## 〇、设计原则（先立规矩）

1. **坐标是环境事实，不是人群标签**：本文所有条目描述"这个地方的环境怎么样"，禁止推导"这个地方的人怎么样/风险高"。
2. **差异 = 环境适应结果，不是优劣**：口味、作息、性格都是对气候与资源的适应；任何表达必须带成因解释。
3. **匹配与风险判断只基于个体数据**（检测/征信/自评），地域仅作环境背景（医疗可及性、生活提示）——与《04》§3.2 反地域歧视规则同一套可执行条款。
4. **用途**：现充管线跨地域磨合建议 + 许愿管线地域联姻缘分卡 + 地域性格雷达 6 轴的环境成因解释层。

## 一、第一层：绝对环境坐标

### 1.1 气候带与分界线（地理学标准）

| 分界线 | 性质 | 依据（来源） |
|:---|:---|:---|
| 秦岭-淮河线 | 800mm 等降水量线 ≈ 1 月 0℃ 等温线 = 暖温带/亚热带 + 湿润/半湿润 + 水田/旱地 + 南北分界 | 人教版地理教材（学科网知识清单，2026-09-04）；人民网科普"秦岭-淮河是条什么线" |
| 400mm 等降水量线 | 半湿润/半干旱分界，大致与长城-农牧交错带一致（北方农区 vs 西北牧区） | 同上教材口径 |
| 胡焕庸线（黑河-腾冲） | 人口密度分界：东南 36% 土地养约 96% 人口，西北 64% 土地约 4% | 胡焕庸《中国人口之分布》（《地理学报》1935）；华东师大人口所 |
| 温度带 | 寒温带/中温带/暖温带/亚热带/热带 | 地理教材标准 |

### 1.2 集中供暖分界（用户点题：南方淮河以南没有暖气）

| 事实 | 说明 | 来源 |
|:---|:---|:---|
| 分界：秦岭-淮河以北集中供暖 | 1950 年代能源奇缺背景下由中央政府划定（界定标准：累年日平均气温稳定 ≤5℃ 的日数 ≥90 天）；**是政策惯例而非单一名文法规条款** | 住建部前副部长仇保兴公开口径（央视网 2013-01-03）；五部委《热电联产管理办法》发改能源〔2016〕617 号第七条书面承接"秦岭、淮河以北"（国务院公报 2016 年第 20 号） |
| 南方无集中供暖现状 | 发改委：南方与北方气候/建筑保温/能源禀赋差异大，"不能照搬北方集中供暖模式"，走"分散式、低能耗、清洁化"多路径探索 | 国家发改委（2025-12-24） |
| 体感影响 | 淮河以南冬季室内温度可能低于室外体感（无暖气+高湿），"屋里比屋外冷"；北方人无法想象南方冬天的手脚冰凉 | 生活常识（C 档） |

### 1.3 七维度坐标（每地域可填值，v1 为定性地带值）

| 坐标维度 | 说明 | 取值方式 |
|:---|:---|:---|
| 干湿 | 湿润/半湿润/半干旱/干旱（400mm/800mm 线界定） | 按城市映射 |
| 温度带 | 暖温带/亚热带等 | 按城市映射 |
| 湿度 | 年均相对湿度（如南方 75-85%、北方 40-60%） | 气象数据 |
| 海拔 | 低海拔平原/高原（如云贵 1000-2000m、青藏 3000m+） | 地理数据 |

| 水质硬度 | 北方偏硬/南方偏软（地质数据） | 市政供水数据 |

| 主要过敏原 | 北方秋季蒿草/葎草/豚草花粉；南方尘螨/霉菌 | 疾控/医学来源 |

## 二、第二层：环境 → 身体反应映射（逐项标证据档位）

| 环境 | 身体反应 | 证据档位 |
|:---|:---|:---|
| 干（北方冬季/暖气房） | 皮肤干燥/呼吸道黏膜干裂/鼻腔出血 | B（医学常识+临床描述） |
| 湿（南方梅雨/回南天） | 体感闷热/湿疹/关节不适（风湿类） | B |
| 南方无暖冬天 | 屋里比屋外冷/手脚冰凉/睡眠受影响 | B（体感+睡眠研究） |
| 热（华南） | 出汗多/电解质流失/食欲下降 | A（生理学） |
| 高海拔 | 血氧下降/睡眠变浅/初到缺氧 | A（高原医学） |
| 强紫外线（高原/南方） | 皮肤光老化加速（对应 Glogau 轴）/晒伤 | A（皮肤医学） |
| 花粉/粉尘 | 过敏性鼻炎/哮喘（秋季蒿草高发） | A（见下） |
| 水质硬 | 脱发/结石风险争议（关联性证据，非定论） | C（有争议，谨慎表述） |

**花粉过敏数据**（A 档）：中国过敏性鼻炎患病率 2005 年 11.1% → 2011 年 17.6% → 2019 年 20.7%（中华医学会三次全国流调）；2023 年 31 省抽样估算患者超 2.8 亿（中国新闻网 2026-09-15）；北方夏秋季（8-9 月）以蒿属/葎草/藜科/苋科/豚草为主，蒿属致敏率高达 88.51%（中国疾控中心科普 2026-09-24）——**用户提的"茼蒿粉过敏"实为蒿草花粉过敏（秋季北方）**，已在产品文案中校正表述。

## 三、第三层：环境 → 工作生活习惯

| 习惯 | 地域差异 | 成因解释 |
|:---|:---|:---|
| 午休文化 | 南方普遍（尤其夏热地区），北方较少 | 南方夏季午后高温（避开最热时段）+ 湿热消耗大；北方夏季短 |
| 作息时差 | 东西部实际时差（新疆与东部差约 2 小时），西部晚睡晚起 | 地理经度时区；日照节律 |
| 夜生活形态 | 南方夜市文化（华南/西南夜市、烧烤摊），北方冬季夜生活短 | 南方夜间气温适合户外；北方冬季夜晚太冷 |
| 办公室环境 | 北方暖气干热（冬季室内 22-26℃ 干）vs 南方空调冷湿（夏天空调房内外温差大） | 供暖/制冷方式差异 |
| 雨季/冬季短昼 | 南方梅雨（江南 6-7 月）、华南雨季影响户外活动；北方冬季短昼（哈尔滨 12 月日照约 8h） | 气候带日照时长 |
| 户外活动季节 | 东北夏季黄金季（冬季漫长）、南方四季可户外但夏热 | 温度带 |

## 四、第四层：环境 → 饮食口味（必须带成因解释）

> 原则：**口味差异 = 环境适应结果，不是优劣**。这是防地域歧视的关键表达，所有口味条目必须成对出现（成因 + 适应逻辑）。

| 口味格局 | 地域 | 成因解释（来源） |
|:---|:---|:---|
| 米 vs 面（主食分界） | 秦岭-淮河以南米/以北面 | 南方雨量丰富宜水稻、北方春旱宜耐旱小麦（中国气象局《舌尖上的"气候密码"》2014-04-21；地理教材） |
| 北咸 | 北方普遍高盐 | 冬季漫长寒冷需更多钠离子维持体温 + **冬季缺乏新鲜蔬菜，盐腌保存是必然的生存智慧**（人民日报海外版《咸味的分寸》2025-12-12） |
| 川渝湘黔辣 | 西南/华中 | 终年阴湿气候（"一年之中具湿冷气候的川、贵、湘嗜辣"，《地理学报》《中国饮食文化的区域分化和发展趋势》） |
| 华南清淡保鲜 | 粤桂琼 | 湿热气候食物易腐，清蒸/白灼保鲜 + 汤水养生 |
| 江南甜口 | 苏浙沪 | 富庶产糖区历史 + 炎热气候甜食快速供能、提升食欲（人民日报海外版同文） |
| 山西酸 | 晋 | 醋文化——气候/水质+历史酿造传统（C 档综合） |
| 西北奶肉 | 陕甘青宁新 | 牧区经济基础（400mm 线以西牧业为主）+ 高原寒地高热量需求（地理教材口径） |

## 五、跨地域结合预测器（规则引擎）

### 5.1 原理

两地坐标差异 → 生成三类输出：**惊奇点**（对方环境里你完全没概念的事）、**困难点**（需要磨合的适应成本）、**互补优势点**（性格/生活方式/资源视野的互补）。全部带环境成因解释，禁止价值排序。

### 5.2 规则引擎（地域对 × 维度差 → 预测文案）

| 维度差 | 规则 | 输出示例 |
|:---|:---|:---|
| 供暖差（北-南） | 北方人→南方：提醒"冬天屋里比屋外冷，取暖靠抖+电暖器"；南方人→北方：提醒"屋里 25℃ 别穿太多，出门 5 分钟冻透" | 惊奇点 |
| 干湿差 | 干→湿：防潮/湿疹/衣服晒不干；湿→干：保湿/流鼻血/静电 | 困难点 |
| 主食差 | 米/面磨合："今天吃米还是吃面"是第一课；互相带对方吃自己家的碳水 | 困难点/浪漫点 |
| 口味差 | 高盐 vs 清淡、辣 vs 不辣：约好"微辣起步"；互相安利家乡菜=浪漫点 | 困难点/浪漫点 |
| 海拔差 | 高原→平原：醉氧；平原→高原：初到血氧下降，3 天适应期 | 困难点 |
| 时差/作息差 | 西部 vs 东部时差约 2h：视频时间协调 | 困难点 |
| 性格互补（接地域性格雷达 6 轴） | 东北豪爽×华东精致、西南宠溺×华北局气：互补优势 | 互补点 |
| 资源视野互补 | 一线×新一线、沿海×内陆：信息差互补 | 互补点 |

### 5.4 双管线复用

- **现充管线**（P8-4 提示词）：两人地域坐标 → 惊奇/困难/互补建议（含"在哪一起生活"的现实权衡：医疗可及性、生活成本）。

## 七、惊讶指数高的发现（单独成节）

1. **秦岭-淮河供暖线是"政策惯例"不是法律条款**：1950 年代能源奇缺背景下划定（标准：日平均 ≤5℃ 天数 ≥90），现行法规（发改能源〔2016〕617 号）只是书面承接——这条线其实从没被一条"法律"正式画过。
2. **过敏性鼻炎 20 年翻倍**：11.1% → 17.6% → 20.7%，患者超 2.8 亿；北方秋季蒿草致敏率 88.51%——"南方的北方人"秋天会突然开始过敏，这是最典型的跨地域惊奇点。
3. **"茼蒿粉过敏"是常见误记**：秋季过敏性鼻炎的元凶是蒿草/豚草花粉（菊科），不是茼蒿菜本身——产品文案已校正。
4. **胡焕庸线 90 年未破**：1935 年提出（东南 36% 土地养 96% 人口），历次人口普查验证稳定——"东西差异"是结构性的，但因此更要只做环境背景、不做价值排序。
5. **北方高盐是"生存智慧"**：冬季没鲜菜→盐腌保存→高盐口味固化；人民日报海外版给了权威背书——"北咸"不是口味偏好问题，是环境适应史。
