# 建模 03 · 铝盆友需求真相与真伪需求

> 用途：yourGirlFriend（铝盆友）仓库的深度需求分析——回应"凭什么 YB 那么长、YG 这么短"，给铝盆友完整的对等研究。
> 方法：同 YB 侧——全 Issue 通读 + 逐条判真/假 + 场景还原；外加女性向市场特殊性（乙女游戏、女性消费、男色经济）。

---

## 一、开场：铝盆友不是蓝盆友的附庸

- 2015 年 YB 评论区一条"对应的铝朋友版本也请同步开发"催生 YG；11 年里 YG 独立积累了 114 条许愿评论、15 个开放 Issue。
- 铝盆友面对的用户几乎全部是**女性与 LGBTQ+**，她们的诉求和 YB 的男性向 YY 有系统性差异（详见下文），产品必须独立建模。
- 结论先行：铝盆友的"方向"不是"女版蓝盆友"，而是**"女性向情绪价值 + 关系教练 + 欲望安全出口"**三合一。

## 二、114 条评论 + 15 个 Issue 通读后的六大真需求

| # | 真需求 | 证据（原话） | 本质 | 与 YB 的差异 |
|:---|:---|:---|:---|:---|
| G1 | 卖萌 / 可爱 / 温柔 | "负责卖萌与鼓励""说话卖萌""要可爱一点"（出现频次第一） | 被治愈感 | YB 高频词是"脾气好"，YG 高频词是"卖萌/可爱"——女性向更看重"被哄"的体验而非"不惹我" |
| G2 | 陪伴与谈心 | "能在一起聊聊天，谈谈心就好""陪我聊电影、聊书、聊游戏" | 深度陪伴 | 女性向的陪伴=情感交流（叙事型），男性向的陪伴=共处/任务型（打游戏/写代码） |
| G3 | 定时关怀 | "叫起床""提醒吃饭""多喝热水""催 ddl" | 被惦记 | 与 YB 同源，但 YG 强调"温柔地提醒"（语气），YB 强调"能干地搞定"（能力） |
| G4 | 情侣配对 / 真人连接 | "偶尔男女朋友的用户能即时交流一下就无敌了"（全场最高赞） | 从虚拟到现实的桥梁 | YB 没有对应的强需求（男性向更自我中心），这是 YG 独有的社交金矿 |
| G5 | 身体亲密 / 性 | "sex 极其重要"（+1:−1=5:1）"每天早晨口醒""暖床" | 欲望出口 | 两边都有，但 YG 的表述更"情感化"（暖床、早晨醒），YB 更"物理化"（会震动、会叫） |
| G6 | 定制 / 捏人 | "DIY女票""捏人""最好是个机器人，用代码表示属性" | 创造欲 | YG 的捏人需求远比 YB 强——女性向的"打扮/养成"属性天然更强 |

## 四、铝盆友的核心差异：女性向市场的三块金矿

### 4.1 情绪价值是女性向的第一付费点

- 乙女游戏市场 2024 年约 80 亿元（+124.1%），恋与深空单款 58.7 亿（占 73%）——情绪价值消费已被验证。
- 女性更愿意为"被爱着的感觉"持续订阅（游戏内购、谷子消费、付费陪伴）。

### 4.2 "关系教练"定位（YG 独有）

- G4（情侣配对）最高赞说明女性用户渴望"现实关系"的帮助，不只是虚拟替代。
- 铝盆友可以同时是"AI 恋爱教练"：帮用户分析聊天记录、练习表白、模拟约会、复盘分手——这是 YB 完全不需要的差异化。

### 4.3 欲望的安全出口（女性向性消费的"去羞耻化"）

- 女性情趣市场在快速增长但供给粗放；"温柔的、有叙事的、不羞辱的"亲密内容是空白。
- YG 的 R 档应该走"女性友好"路线：重叙事、重氛围、重 consent（同意文化），与 YB 的"直给"风格区隔。

## 五、暖床需求的正确读法（真实意图 vs 字面理解）

| 字面 | 真实意图 | 产品含义 |
|:---|:---|:---|
| 暖床（电热毯） | 不是真要一个会发热的人，是要"被照顾、被安排得舒舒服服" | 关怀行为的温度感知：调好空调、铺好被子、提前预热 |
| 每天早晨口醒 | 想要"被爱唤醒"的仪式感 | 晨间关怀流程：早安语音 + 今日天气 + 贴心提醒 |
| 拥抱 | 想要"被抱住"的安全感 | 具身化：抱枕形态 + 心跳模拟 + 体温模拟（IoT） |

**教训**：铝盆友的需求不能按字面做硬件，要做"需求背后的需求"。

## 六、场景 × 痛点 × 付费强度（铝盆友）

| 场景 | 痛点 | 付费强度 |
|:---|:---|:---|
| 深夜独处 / 异地恋 | 想被陪着睡、想被哄 | 高 |
| 工作压力 / 情绪崩溃 | 要一个温柔承接 | 高 |
| 被催婚 / 相亲焦虑 | 想要"恋爱练习"和底气 | 中高 |
| 恋爱中但没被爱着 | 要仪式感、要证据 | 高 |
| 单身且有欲望 | 要安全、不羞耻的出口 | 高（R 档） |
| 想倾诉但不想麻烦朋友 | 要一个不评判的树洞 | 中 |

## 七、对重启的推论（铝盆友侧）

1. 铝盆友产品内核 = **情绪价值 + 关系教练 + 欲望安全出口**，不是"女版蓝盆友"。
2. MVP 优先验证：卖萌陪伴（G1/G2）与情侣配对（G4）——一个验证情绪付费，一个验证社交裂变。
3. 捏人（G6）是铝盆友最强的 UGC 入口：女性向的捏人=打扮/养成/分享，天然传播。
4. 铝盆友的商业计划见《建模 04》。
